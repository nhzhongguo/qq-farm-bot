## 2. 优化清单（按排期）

### 2.1 P0 — 质量门修复（0.5 人日）
| 项 | 措施 | 预期 |
|----|------|------|
| Lint 6 错误 | 4 处 `--fix` + 2 处手改（删未用 `rule`、对象简写） | CI 转绿 |
| 构建回归钩子 | CI 增加 `pnpm build:web && pnpm test` | 阻断回归 |

### 2.2 P1 — Bundle 体积
| 项 | 措施 | 预期 |
|----|------|------|
| 首屏拆包 | 确认每个路由视图均已 lazy；`AdminPanel/Settings` 已拆（65.3/53.6 KB），检查 `DefaultLayout`（31.7 KB）与 `index` 是否可再拆 |
| 图标按需 | UnoCSS presetIcons 已是按需；确认无整包 import `@iconify-json` 全量 |
| 依赖审查 | 用 `knip`/`depcheck` 找未用依赖；`nprogress` 是否仍用、`@vueuse/core` 按需导入 | 预计 JS 再降 5–10% |
| gzip/brotli | 已产出 .gz；补 brotli 静态压缩（nginx `brotli on`） | 传输再降 ~15% |

### 2.3 P1 — 图片优化
| 项 | 措施 | 预期 |
|----|------|------|
| seed_images_named（230 张 PNG / 949 KB） | 批量转 WebP（sharp）+ 保留原图目录做回退 | 体积 -60%+（约 -570 KB） |
| 懒加载 | 非首屏图片 `loading="lazy"`（FarmPanel 地块图） | 首屏 LCP 提升 |
| CDN | 静态资源走 CDN + `Cache-Control: immutable`（指纹文件名已具备） | 命中缓存零请求 |

### 2.4 P2 — 网络与缓存
| 项 | 措施 |
|----|------|
| 静态资源缓存 | `assets/*`（指纹）`max-age=31536000, immutable`；`index.html` `no-cache` |
| 接口数据缓存 | 种植配置（`seed_images_named`/作物数据）前端 SWR 缓存 + 版本化 |
| 请求合并 | 登录/状态轮询合并；WS 已用于实时状态，HTTP 轮询路径降频 |
| HTTP/2 | 生产部署启用 h2（部署层配置） |

### 2.5 P2 — 后端与构建升级评估
| 项 | 评估 | 建议 |
|----|------|------|
| **Express 5 迁移** | breaking 点：`*` 通配符路由需改 `/*splat`、异步错误自动传递行为变化、`res.sendfile` 更名 | **不急于升**：先跑兼容层验证核心路由（auth/qr/ws），列迁移用例清单；若影响面大（路由较多）保留 4.x 并记录风险 |
| **Vite 8** | 需验证 `@vitejs/plugin-vue` / unocss 插件兼容；构建产物应兼容 | 单开分支升级验证，预计构建更快（rolldown 收益） |
| **TS 7** | 新架构编译器 | 观望 ≥1 个小版本后再评估 |
| JSON→SQLite | 当前 `core/data/*.json` 读写全量；数据量增长后（登录日志/种植记录）改为 `better-sqlite3` 或文件分片 | P2 评估项：先做基准（>10 万条记录时 JSON 全量读写的延迟/内存） |
| 慢查询/N+1 | 无 SQL 层；JSON 访问集中 `json-db.js`，先做缓存层（内存 Map + 写合并） | 低风险高收益 |

### 2.6 P2 — 渲染与内存
| 项 | 措施 |
|----|------|
| 虚拟列表 | Friends 列表 / 日志表格数据量大时用虚拟滚动（`@vueuse/virtual-list` 或自研） |
| 防抖/节流 | 设置页即时保存、搜索输入防抖 |
| 内存 | 检查 WS/定时器清理（组件卸载 `onUnmounted`）；Toast 队列上限 |
| 骨架屏 | 首屏数据加载用骨架屏代替白屏（配合 02-UI 方案） |
