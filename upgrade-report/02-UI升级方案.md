## 2. 升级方案（按优先级排序）

### P0 — 无障碍达标（WCAG 2.1 AA）
1. **BaseSelect 键盘可达**：补 `role="listbox"/"option"`、`aria-expanded`、`aria-activedescendant`、↑↓/Home/End/Enter/Esc 键盘处理、失焦关闭（现只有 document click 关闭）。
2. **图片 alt 全量补全**：`WxLoginModal` 等 `<img>` 加有意义 alt；装饰图加 `alt=""`。
3. **`lang="zh-CN"`** + 删除隐藏 iframe 怪癖。
4. **Modal 焦点管理**：打开聚焦、Tab 循环（焦点陷阱）、关闭还原焦点；ConfirmModal/AccountModal/WxLoginModal 统一。
5. **语义化**：导航用 `<nav>`、图标按钮补 `aria-label`（Sidebar 汉堡按钮等）。

### P1 — 设计 Token 补全
1. 迁移 `LandCard.vue` 25 处拟物色 → `--color-land-*` 系列（随主题联动）。
2. 迁移 `Statistics.vue` 7 处图表色板 → `--color-chart-1..7`（8 主题下可读性一致）。
3. 迁移 `Login.vue` / `Sidebar.vue` 残留色 → semantic Token。
4. 魔法值收口：`Statistics.vue` 图表高度 → `--chart-height`（`clamp()` 自适应）。

### P2 — 状态统一与动效
1. **骨架屏**：Dashboard/Settings 首屏用 `BaseSkeleton`（新增）替代白屏；`Skeleton` 动效用 svg-spinners 统一。
2. **空态/错误态统一**：`EmptyState.vue` 已存在，扩展为三态组件（Loading/Empty/Error + 重试按钮），全视图接入。
3. **微交互**：卡片 hover 阴影过渡统一用 `--motion-duration-*` + `--shadow-*`；页面切换加 `Transition`（参考 AccountModal 已修复的 fade）。
4. **图表响应式**：分析页 SVG 高度改容器自适应（`aspect-ratio` + 100% 宽）。

### P3 — 体验细节
1. 字体：中文优先栈统一为 `system-ui + PingFang/MiSans/Noto Sans SC`；数字用 tabular-nums。
2. 图标：carbon 全量替换 fas 5 处遗留，保证单一来源。
3. 主题：新增「跟随系统」选项（`prefers-color-scheme`），并补充每主题对比度检测。
